## 🧠 Problem-Solving Approach

For problems where applicable, I try to understand the solution progressively:

```text
Brute Force
     ↓
Better Approach
     ↓
Optimal Approach
````

### Example

```text
O(n³) → O(n²) → O(n)
```

The goal is not only to solve the problem, but also to understand:

* Why the solution works
* How to optimize the solution
* Time and space trade-offs
* When to use a particular approach

## 📝 Solution Format

For problems where multiple approaches are possible, solutions are organized as:

### 1. Brute Force

The straightforward approach used to understand the problem.

### 2. Better Approach

An improved solution that reduces unnecessary operations.

### 3. Optimal Approach

The most efficient solution based on time and space complexity.

### Example

**Problem:** Subarray Sum Equals K

| Approach    | Time Complexity | Space Complexity |
| ----------- | --------------- | ---------------- |
| Brute Force | O(n³)           | O(1)             |
| Better      | O(n²)           | O(1)             |
| Optimal     | O(n)            | O(n)             |
